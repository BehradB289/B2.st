## ✨ Features

- 🔗 **URL Shortening** — Generate short links with custom or auto-generated codes
- 👤 **Bio Page** — Personal landing page with all your links
- 📊 **Real-time Analytics** — Track clicks, devices, countries, referrers
- 🔐 **JWT Authentication** — Secure stateless auth
- ⚡ **Fast** — SQLite + Express, no external DB needed
- 🐳 **Docker Ready** — One-command deployment

## 🚀 Quick Start

```bash
npm install
cp .env.example .env
npm run migrate
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
