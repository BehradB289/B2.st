# 🎮 Super Mario Bros - B2.st Studio Edition

یک بازی سوپر ماریو کامل با HTML5 Canvas و JavaScript خالص - بدون هیچ وابستگی خارجی.

## 🚀 اجرای سریع

```bash
# روش ۱: مستقیم در مرورگر
open index.html

# روش ۲: با سرور محلی
npm install
npm start

# روش ۳: توسعه
npm run dev
```

## 🎯 کنترل‌ها

| کلید | عملکرد |
|------|--------|
| ← → | حرکت |
| SPACE / ↑ | پرش |
| SHIFT | دویدن |
| P | توقف/ادامه |
| M | قطع/وصل صدا |

## 📁 ساختار پروژه

```
mario-game/
├── index.html              # فایل اصلی بازی (کاملاً مستقل)
├── package.json            # تنظیمات npm
├── .env                    # متغیرهای محیطی (gitignored)
├── .env.example            # نمونه متغیرهای محیطی
├── .gitignore              # فایل‌های نادیده‌گرفته‌شده
├── README.md               # مستندات
└── config/
    ├── env_config.js       # ماژول پیکربندی محیطی ۱۰ لایه
    └── security_check.js   # بررسی امنیتی پیش از دیپلوی
```

## 🔒 امنیت

```bash
# اجرای بررسی امنیتی
npm run security-check

# اعتبارسنجی متغیرهای محیطی
npm run validate-env
```
