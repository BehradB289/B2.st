# معماری موتور بازی ماریو استودیو B2.st

این مستند تشریح‌کننده ساختار ماژولار شی‌گرا و الگوی سیستم-موجودیت سبک بازی Super Mario بر بستر Canvas 2D و JavaScript ES6+ می‌باشد.

## ۱. ساختار لایه‌بندی پروژه

```
├── config/
├── docs/
│   └── ARCHITECTURE.md
├── public/
│   ├── index.html        # رابط کاربری با شل شبیه‌ساز مانیتور CRT رترو
│   └── style.css          # استایل کنسول NES، فونت پیکسلی و ریسپانسیو
├── src/
│   ├── engine/
│   │   ├── Audio.js       # سنتز چنل‌های صوتی Chiptune با Web Audio API
│   │   ├── Camera.js      # دوربین اسکرول با Deadzone کلاسیک NES
│   │   ├── GameLoop.js    # چرخه بازی مبتنی بر Delta-Time
│   │   ├── InputHandler.js# مدیریت رویدادهای چندکلیدی کیبورد
│   │   ├── Physics.js     # موتور تشخیص برخورد AABB و گرانش پیوسته
│   │   └── Vector2D.js    # کلاس ریاضی بردار ۲ بعدی
│   ├── entities/
│   │   ├── Entity.js      # کلاس پایه انتیتی‌ها با هوک‌های برخورد و انیمیشن
│   │   ├── Goomba.js      # هوش مصنوعی گومبا، له شدن و پاک‌سازی
│   │   └── Mario.js       # FSM، اینرسی، پرش متغیر و حالت Small/Super
│   ├── levels/
│   │   ├── Level1.js      # لایه‌بندی مرحله ۱-۱، لوله‌ها، آجرها و دشمنان
│   │   └── TileMap.js     # نقشه کاشی‌ها، مدیریت برخورد جامد
│   └── game.js            # ارکستراتور مرکزی بازی
└── tests/
    └── physics.test.js    # پایپ‌لاین تست‌های واحد فیزیک، اینرسی و استامپ
```

## ۲. ماشین حالت انتیتی کاراکتر ماریو (Mario FSM)
حالت‌های رفتاری ماریو عبارتند از:
- `IDLE`: ایستاده در سکون
- `WALKING`: گام‌برداری با اینرسی و شتاب `360 px/s²`
- `RUNNING`: دویدن با نگه‌داشتن کلید Dash تا سقف `210 px/s`
- `SKIDDING`: ترمز کشیدن همراه با تغییر جهت ناگهانی و اصطکاک بالا
- `JUMPING`: پرش با شتاب منفی اولیه و پایداری در اثر نگه‌داشتن کلید پرش
- `FALLING`: سقوط آزاد تحت شتاب گرانش `1100 px/s²`
- `CROUCHING`: حالت نشستن برای سوپرماریو
- `DEAD`: پرتاب مرگ و سقوط از صفحه بدون برخورد

## ۳. نحوه اجرای پروژه و تست‌ها
برای اجرای پروژه بدون نیاز به بیلد تولز پیچیده:
1. استفاده از یک وب‌سرور لوکال استاندارد:
   ```bash
   npx serve .
   # یا
   python3 -m http.server 8000
   ```
2. ورود به آدرس `http://localhost:8000/public/`
3. اجرای تست‌های فیزیک:
   ```bash
   node tests/physics.test.js
   ```
