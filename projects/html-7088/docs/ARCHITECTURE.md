# استودیو بازی‌سازی B2.st - مستندات معماری موتور بازی Super Mario NES

این مستند تشریح‌کننده ساختار ماژولار و مهندسی نرم‌افزار پیاده‌سازی شده برای پروژه بازآفرینی سوپر ماریو کلاسیک بر پایه HTML5 Canvas و جاوااسکریپت مدرن (ES6+) است.

## ۱. ساختار لایه‌ها (Layered Architecture)

```
┌────────────────────────────────────────────────────────┐
│                   Public UI / Shell                    │
│     (Canvas Viewport, HUD Controller, Retro Styles)    │
└───────────────────────────┬────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│                    Game Core Engine                    │
│       GameLoop ──► Physics (AABB) ──► Camera 2D        │
└─────────────┬───────────────────────────┬──────────────┘
              │                           │
┌─────────────▼───────────────┐ ┌─────────▼──────────────┐
│       Entities Layer        │ │      Levels Layer      │
│  Mario, Particles, Mystery  │ │  TileMap, Tile Culling │
│   Blocks, Brick Debris      │ │  World 1-1 Generator   │
└─────────────────────────────┘ └────────────────────────┘
```

## ۲. مشخصات فنی مؤلفه‌ها

### الف) موتور مرکزی (`src/engine/`)
* **Camera (`Camera.js`):**
  * مدیریت اسکرول افقی تک‌جهته (One-way horizontal scrolling) مطابق استاندارد NES.
  * سیستم فیلترینگ و برش دید (Frustum / Viewport Culling) برای جلوگیری از رندر تایل‌های خارج از صفحه.
  * جلوگیری از بازگشت ماریو به سمت چپ کادر دوربین (Deadzone Clamping).
* **Physics (`Physics.js`):**
  * پیاده‌سازی برخورد AABB (Axis-Aligned Bounding Box) با تفکیک بردار حرکت محورهای افقی و عمودی جهت رفع اثر تونل‌زنی (Tunneling).
  * تشخیص برخورد سر کاراکتر با زیر بلوک‌ها (Head-bump collision) برای فعال‌سازی مکانیک تایل‌های تعاملی.
* **GameLoop (`GameLoop.js`):**
  * الگوریتم حلقه زمان ثابت (Fixed Timestep Accumulator) جهت پایداری شبیه‌سازی فیزیک مستقل از نرخ تازه‌سازی نمایشگر (Refresh Rate).
* **Audio (`Audio.js`):**
  * سینتی‌سایزر صوتی سبک با Web Audio API برای تولید افکت‌های صوتی رترو (پرش، دریافت سکه، ضربه به بلوک و شکستن آجر) بدون وابستگی به فایل‌های خارجی.

### ب) سیستم تایل و مراحل (`src/levels/`)
* **TileMap (`TileMap.js`):**
  * مدیریت ماتریس تایل‌ها با ابعاد استاندارد ۱۶×۱۶ پیکسل رترو.
  * پردازش وضعیت تایل‌های پویا: بلوک‌های علامت سوال (`?`) سکه‌دار، تبدیل به بلوک خالی (`Empty/Used Block`)، انیمیشن جهش الاستیک تایل (Tile Bumping) و بلوک‌های آجری خردشونده.
* **World 1-1 (`World1_1.js`):**
  * نقشه مهندسی‌شده مرحله ۱-۱ با جزییات تایل‌های زمین، لوله‌های سبز در ارتفاع‌های مختلف، پله‌های هرمی، ابرها و بوته‌های تزیینی.

### ج) سیستم هویت‌ها و ذرات (`src/entities/`)
* **Mario (`Mario.js`):**
  * کنترل‌کننده وضعیت فیزیکی (ایستادن، دویدن، جهش، ترمز)، رندر پیکسلی و هندسه برخورد.
* **Particles (`Particle.js`):**
  * سیستم ذرات شامل خرده‌های ۴ گانه آجر با شتاب گرانش و چرخش زاویه‌ای، سکه جهنده و متن امتیاز شناور (`+200`).
