# استودیو B2.st - گزارش تغییرات و مشخصات فنی (Changelog)

## آپدیت بزرگ: تزریق فرمانده (Commander Update v2.0)

### 🌟 ویژگی‌های جدید و پیشرفته:
1. **موتور صوت چنل‌های صوتی ۸ بیتی چیپ‌تیون (Web Audio API):**
   - بدون نیاز به فایل‌های خارجی سنگین یا لینک‌های منقضی شونده.
   - تولید لحظه‌ای فرکانس‌های موج مربعی (Square), مثلثی (Triangle) و نویز (Noise) برای:
     - پرش‌های کوچک و بزرگ
     - صدای نوستالژیک سکه (B5 به E6)
     - له کردن گومبا، ضربه به لاکپشت، شلیک گلوله آتشین و خوردن قارچ
     - ملودی موزیک مرحله ۱-۱ و افکت سوت پیروزی پایین آمدن پرچم.

2. **سیستم کامل کاراکتر ماریو (State Machine):**
   - حالات رشد: **Small Mario** -> **Super Mario** (۳۲ پیکسلی) -> **Fire Mario** -> **Star Mario**.
   - شلیک آتش با کلید Shift / B در حالت فایر ماریو.
   - حالت ستاره شکست‌ناپذیر با چرخه رنگین‌کمانی پالت NES.
   - نشستن (Crouch) برای سوپر ماریو و لیز خوردن هنگام تغییر جهت ناگهانی.

3. **دشمنان کلاسیک با فیزیک دقیق:**
   - **Goomba:** راه رفتن و له شدن زیر پای ماریو با انیمیشن فلت شدن.
   - **Koopa Troopa:** سیستم دو مرحله‌ای؛ تبدیل شدن به لاک، پرتاب شدن لاک با لگد، برخورد به دیوارها و کشتن دشمنان دیگر در مسیر.

4. **سیستم تایل‌مپ تعاملی و پرتاب ذرات (Particle Engine):**
   - بلوک‌های علامت سوال `?` دارای انیمیشن پرش رو به بالا (Bump Physics) و تبدیل شدن به Used Block.
   - آجرهای قهوه‌ای: پرش برای ماریو کوچک و خرد شدن به ۴ تکه چرخان برای سوپر ماریو همراه با ارتعاش تصویر (Screen Shake).
   - انیمیشن سکه شناور و پرواز امتیازها (`100`, `200`, `1000`).

5. **طراحی رترو و شبیه‌ساز CRT:**
   - افکت اسکن‌لاین (Scanline) قابل سوئیچ با دکمه CRT FX.
   - شبیه‌ساز کلیدهای لمسی (Virtual D-Pad) مخصوص گوشی و تبلت.
   - پشتیبانی از گیم‌پد (Gamepad API استاندارد).
