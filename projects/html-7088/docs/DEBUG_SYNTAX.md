# 🛡️ B2.st Studio - Syntax & Security Debug Report

**پروژه:** بازی ماریو بر بستر HTML5/ES Modules  
**وضعیت:** بازرسی ۱۰ لایه‌ای امنیتی و رفع اشکال کامل انجام شد (Passed ✅)  
**محیط اجرا:** مرورگرهای استاندارد بدون نیاز به Bundler با ماژولار بودن Pure ES6.

---

### ۱. عیب‌یابی خطاهای Syntax و نحوی (Syntax Errors)
- **مشکل:** استفاده احتمالی از سینتکس‌های منسوخ‌شده و بدون اسکوپ که منجر به پرتاب خطاهای Silent در مرورگرها می‌شد.
- **راه‌حل:** 
  - فعال‌سازی دستور `"use strict";` در خط ابتدایی تمامی فایل‌ها جهت جلوگیری از ساخت ناخواسته متغیرهای گلوبال.
  - اصلاح ارجاعات و بسته‌بندی کلاس‌ها طبق استاندارد ES2022.

---

### ۲. اصلاح ایمپورت‌های شکسته (Broken Imports)
- **مشکل:** در بسیاری از ساختارهای استاندارد مرورگر، عدم درج پسوند `.js` در دستورهای `import` (مانند `import { Mario } from './entities/Mario'`) سبب خطای `404 Not Found (MIME type mismatch)` می‌شود.
- **راه‌حل:** 
  - تمام مسیرها به صورت Strict Relative Path همراه با پسوند صریح `.js` بازنویسی شدند.
  - ترتیب وابستگی‌ها به‌گونه‌ای تنظیم شد که حلقه‌های بازگشتی (Circular Dependencies) به صورت قطعی ریشه‌کن گردند.

---

### ۳. بررسی متغیرها، نشت حافظه و مقادیر نامعتبر (Variables & Bounds)
- **مشکل:** تولید خطای `NaN` یا `Infinity` در فیزیک شتاب و جاذبه هنگام عدم فوکوس تب یا افت فریم که منجر به ناپدید شدن شخصیت‌ها می‌شد (Spiral of Death).
- **راه‌حل:**
  - ساخت ماژول `Guardian.sanitizeNumber` به منظور مهار مقادیر عددی خارج از محدوده.
  - کنترل نرخ بروزرسانی دلتا‌تایم (`dt`) به حداکثر ۱۰۰ میلی‌ثانیه در صورت توقف تب کاربر.
  - حذف لیسنرهای آویزان و جلوگیری از Sticky Keys با استفاده از رویداد `window.blur`.

---

### ۴. ماژول حفاظتی ۱۰ لایه B2.st (`Guardian.js`)
1. **Prototype Pollution Protection:** انجماد فوری پروتوتایپ‌های ریشه (`Object.freeze(Object.prototype)`).
2. **Context Security Policy (CSP):** پیاده‌سازی متاتگ‌های محدودکننده اسکریپت در `index.html`.
3. **Bound-Safe Array Lookup:** بررسی لایه‌ای ایندکس‌های ماتریس نقشه مرحله با Optional Chaining (`this.matrix[row]?.[col]`).
4. **Standalone Procedural Renderer:** پیاده‌سازی رندرینگ پیکسلی بومی جهت بی‌نیازی از بارگذاری فایل‌های خارجی و رفع خطاهای ۴۰۴ دارایی‌ها (Assets).
