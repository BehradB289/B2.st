# مستندات فنی موتور بازی Super Mario - استودیو B2.st

## ۱. ساختار ماژولار هسته فیزیک و چرخه بازی

این پروژه بر مبنای معماری سبک شی‌گرایی و Entity-Component-System طراحی شده است. تسک فعلی بر پیاده‌سازی لایه زیرین چرخه بازی (Game Loop)، ثبت و مدیریت ورودی‌ها (Input Handling) و شبیه‌سازی فیزیک برخورد دوبعدی (2D AABB Physics Engine) تمرکز دارد.

### نمودار معماری لایه‌ها
```
                    +-----------------------+
                    |    GameLoop (60Hz)    |
                    |  (Fixed Accumulator)  |
                    +-----------+-----------+
                                |
                 +--------------+--------------+
                 |                             |
      +----------v---------+        +----------v---------+
      |    InputHandler    |        |   PhysicsEngine    |
      | (Keyboard Actions) |        | (AABB Axis Resolve)|
      +----------+---------+        +----------+---------+
                 |                             |
                 +--------------+--------------+
                                |
                    +-----------v-----------+
                    |  Entities / Renderer  |
                    |   (Canvas 2D View)    |
                    +-----------------------+
```

## ۲. مشخصات ماژول‌ها

### ۲.۱. چرخه بازی `GameLoop.js`
- **Fixed Timestep Accumulator Pattern**: برای حل مشکل ناهمگامی نرخ فریم در مانیتورهای با رفرش‌ریت متفاوت (مانند 60Hz، 120Hz، 144Hz)، محاسبات فیزیک با زمان دلتای قطعی `1/60s` (حدود 16.66 میلی‌ثانیه) انجام می‌شود.
- **Spiral-of-death Protection**: متغیر `maxAccumulator = 0.2s` برای پیشگیری از انباشت بیش از حد فریم‌ها در صورت افت مقطعی پروسسور مرورگر اعمال شده است.
- **Render Interpolation Alpha**: پارامتر آلفا تفاوت زمانی باقی‌مانده را به متد رندر تحویل می‌دهد تا انیمیشن‌ها بدون بریدگی رسم شوند.

### ۲.۲. موتور فیزیک AABB در `Physics.js`
- **Axis-Separated Resolution**:
  برای جلوگیری از مشکل عبور از موانع در گوشه‌ها (Corner Snapping / Tunneling):
  1. موقعیت در محور X تغییر کرده و برخوردهای افقی حل و سرعت افقی صفر می‌شود.
  2. موقعیت در محور Y تغییر کرده، برخوردهای فرود روی زمین (`isGrounded = true`) و برخورد به سقف بررسی و حل می‌شوند.
- **نیروهای طبیعی**:
  - شتاب گرانش (`gravity`) با سقف سرعت سقوط (`terminalVelocity`).
  - اصطکاک خطی (`groundFriction`) روی زمین و مقاومت ناچیز هوا در پرش.

### ۲.۳. سیستم ورودی `InputHandler.js`
- نگاشت کلیدهای بازی‌های رترو NES به اکشن‌های استاندارد (`left`, `right`, `jump`, `run`, `down`, `pause`).
- پشتیبانی از وضعیت‌های `isDown` (نگه داشته شده)، `isJustPressed` (ضربه تک‌فریم) و `isJustReleased`.
