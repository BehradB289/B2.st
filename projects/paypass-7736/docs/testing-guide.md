# راهنمای اجرای تست‌های یکپارچگی پرداخت و رمزنگاری پی‌پاس (PayPass)

این سوئیت تست توسط استودیو B2.st جهت اعتبارسنجی فرآیندهای مالی، امنیت رمزنگاری متقارن AES-256 و اطمینان از تجربه کاربری بدون اصطکاک توسعه یافته است.

## ساختار تست‌ها
1. **`tests/crypto.test.ts`**:
   - آزمون دقیق رمزنگاری و رمزگشایی متقارن با الگوریتم AES-256-GCM
   - تایید عدم نشت دیتای خام در پی‌لود رمز شده
   - راستی‌آزمایی تصادفی‌بودن IV و تولید سایفرتکست‌های مستقل
   - مقاومت در برابر Tampering روی Ciphertext و AuthTag
   - تست ورودی‌های چندزبانه و متون فارسی

2. **`tests/payment-actions.test.ts`**:
   - شبیه‌سازی Server Actionهای Next.js 14
   - تست دقیق کسر خودکار ۵٪ کارمزد پلتفرم و ۹۵٪ سهم فروشنده
   - اعتبارسنجی وضعیت‌های `pending` و `completed` در جدول Orders
   - تضمین محرمانگی کامل محتوا قبل از تایید قطعی تراکنش بانکی
   - تست قابلیت تکرارپذیری امن (Idempotency)

3. **`tests/e2e-checkout.spec.ts`**:
   - تست سرتاسری با Playwright
   - ارزیابی المان‌های زبان طراحی گلس‌مورفیسم لوکس استودیو B2.st
   - تست جریان ورود ایمیل خریدار، فرآیند تراکنش و مشاهده باکس امن گشایش‌یافته محتوا

## دستورات اجرا

### اجرای تست‌های واحد و سرور اکشن‌ها (Vitest)
```bash
npm run test
# یا با گزارش پوشش کامل
npx vitest run --coverage
```

### اجرای تست‌های سرتاسری (Playwright E2E)
```bash
# نصب مرورگرها در صورت نیاز
npx playwright install --with-deps

# اجرای سناریوهای سرتاسری
npx playwright test
```
