## 📐 Architecture
پروژه /strat یک پلتفرم استراتژی دیجیتال با معماری مدولار MVC است. بک‌اند بر پایه Node.js/Express با لایه سرویس جداگانه، API RESTful و میدلورهای احراز هویت طراحی شده. فرانت‌اند به‌صورت SPA در public/index.html با vanilla JS و CSS مدرن پیاده‌سازی می‌شود. لایه داده با الگوی Repository از دیتابیس جدا شده و config از متغیرهای محیطی خوانده می‌شود. تست‌ها با Jest در پوشه tests/ شامل unit و integration هستند. مستندات فنی و API docs در پوشه docs/ نگهداری می‌شود.
