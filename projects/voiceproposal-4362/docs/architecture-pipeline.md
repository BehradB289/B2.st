# معماری پایپ‌لاین هوش مصنوعی و داده VoiceProposal (استودیو B2.st)

پروژه **VoiceProposal** یک سیستم Serverless روی بستر **Next.js 14 App Router** و مستقر روی زیرساخت **Vercel** است که صوت مذاکرات فریلنسری را در لحظه به پیش‌فاکتور و سند حقوقی کامل تبدیل می‌کند.

---

## ۱. دیاگرام جریان عملیات (Data Flow Pipeline)

```
[ Frontend: Web Audio API ]
             │ (ضبط استریم WebM و ارسال FormData)
             ▼
[ Next.js 14 Server Action: generateProposalAction ]
             │
             ├──▶ ۱. محاسبه هش صوتی SHA-256
             ├──▶ ۲. استعلام کش در دیتابیس Supabase
             │      └── در صورت انطباق هش: بازگشت آنی داده (Cache Hit)
             │
             ├──▶ ۳. ارسال مستقیم استریم صوت به Groq Whisper-large-v3
             │      └── استخراج متن با پرامپت اختصاصی و تاخیر زیر ۱ ثانیه
             │
             ├──▶ ۴. ارسال متن پیاده‌سازی شده به Groq Llama-3-70b
             │      └── پردازش حقوقی + منطق ریاضی + JSON Mode
             │
             ├──▶ ۵. اعتبارسنجی اسکیمای Zod با ProposalSchema
             │      └── در صورت نقص ساختاری: Self-Correction چرخشی
             │
             ├──▶ ۶. ذخیره رکورد و متادیتا در جدول proposals در Supabase
             │
             ▼
[ Client Response: تایپ داده آماده رندر در Glassmorphic UI و صدور PDF با @react-pdf/renderer ]
```

## ۲. مشخصات کلیدی ماژول‌ها

### `src/lib/schemas/proposal.ts`
اسکیمای منسجم Zod که کلیه ملزومات یک قرارداد حرفه‌ای را مدل‌سازی می‌کند:
- **اقلام خدمات (`scopeOfWork`)**: شناسه، عنوان، شرح، تعداد، قیمت واحد، قیمت کل و دسته‌بندی.
- **فازبندی پروژه (`phases`)**: مراحل انجام، تحویل‌دادنی‌ها (Deliverables)، ددلاین و درصد پرداخت مربوطه.
- **جدول مبالغ (`financials`)**: ارز مبنا (تومان، ریال، دلار، یورو)، تخفیف، مالیات، پیش‌پرداخت، باقیمانده و شیوه واریز.
- **بندهای حقوقی (`legalTerms`)**: شرایط فسخ طرفین، فورس‌ماژور (قطع زیرساخت و حوادث قهریه)، بازبینی‌ها و سقف تغییرات (Scope Creep)، محرمانگی (NDA) و مالکیت معنوی (IP).

### `src/lib/groq.ts`
- کلاینت **Groq Cloud** برای اجرای فوق‌سریع مدل‌های هوش مصنوعی.
- تبدیل صوت با مدل `whisper-large-v3` با تنظیم `temperature: 0.0` و پرامپت کلمات کلیدی فناوری.
- متد `generateStructuredProposal` با مدل پرچمدار `llama-3.3-70b-versatile` با سیستم پرامپت حقوقی B2.st.
- پیاده‌سازی متد بازگشتی **Self-Correction** جهت ترمیم خودکار پاسخ در صورت عدم انطباق اعتبارسنجی اولیه.

### `src/lib/supabase.ts`
- کلاینت اختصاصی Service Role جهت ثبت بدون قطعی در محیط‌های Serverless.
- سیستم Deduplication مبتنی بر هش **SHA-256** فایل صوتی جهت جلوگیری از پرداخت هزینه‌های پردازش تکراری و کاهش تاخیر به صفر در صورت ویس تکراری.
- مدیریت فراخوانی، ثبت و به‌روزرسانی وضعیت سند (`draft`, `published`, `accepted`, `rejected`).

### `src/app/actions/generate-proposal.ts`
- سرور اکشن Next.js با دایرکتیو `'use server'` بدون افشای کلیدهای API به سمت کلاینت.
- اعتبارسنجی سایز فایل صوتی (سقف ۲۵ مگابایت)، نوع MIME، و محاسبه تایم‌لاین عملکردی (Metrics).
