# راهنمای آزمون‌های یکپارچه‌سازی پایپ‌لاین هوش مصنوعی و اعتبارسنجی PDF
### استودیو فناوری B2.st | پروژه VoiceProposal

این مستند تشریح‌کننده معماری، سناریوهای آزمون و شیوه اجرای تست‌های یکپارچگی پایپ‌لاین صوت تا پیش‌فاکتور و رندرینگ کلاینت PDF است.

## ۲. سناریوهای تحت پوشش تست‌ها

### الف) تست‌های پایپ‌لاین AI (`tests/ai-pipeline.test.ts`)
1. **ارسال بافر خالی یا نویز کوتاه**:
   - آزمون اعتبارسنجی بافر ورودی قبل از هدر دادن توکن‌های API.
   - دریافت خطاهای `EMPTY_AUDIO_BUFFER` و `AUDIO_TOO_SHORT`.
2. **شبیه‌سازی گفتار نامفهوم (Silence / Noise)**:
   - سناریویی که ترانسکریپت Whisper مقدار سفید یا کمتر از ۵ کاراکتر باشد (`NO_SPEECH_DETECTED`).
3. **تطبیق موفق اسکیما (Happy Path)**:
   - بازگشت ساختار کامل قرارداد و تست سازگاری با Zod Schema.
4. **تزریق پرامپت (Prompt Injection Defense)**:
   - تلاش برای خروج از فرمت قرارداد توسط دستورات انحرافی در پیام صوتی.
5. **مغایرت‌های مالی و ریاضی**:
   - عدم همخوانی جمع ردیف‌ها با فیلد `subtotalAmount`.
   - عدم رسیدن مجموع مایل‌استون‌ها به ۱۰۰ درصد.
   - خطاهای ۵۰۲ در صورت بروز پاسخ غیر JSON از LLM.

### ب) تست‌های رندرینگ PDF (`tests/pdf-render.test.tsx`)
1. **عدم کرش در تایپوگرافی فارسی**:
   - ثبت استاندارد فونت وزیرمتن با `Font.register`.
   - جلوگیری از بروز خطا در کاراکترهای ویژه فارسی (گ، چ، پ، ژ، خط فاصله، نیم‌فاصله).
2. **فرمت‌بندی ریالی و تومان**:
   - بررسی عملکرد جداکننده ۳ رقمی ارقام فارسی (`formatNumberPersian`).
3. **پایداری جدول اقلام طولانی**:
   - تست ایجاد Blob پیش‌فاکتور با بیش از ۸ ردیف خدمت تخصصی و فازبندی‌های مختلف.
4. **شبیه‌سازی دانلود کلاینت**:
   - متد `pdf().toBlob()` بدون وابستگی به سرور در مرورگر کاربر.

## ۳. دستورات اجرای تست‌ها

اجرای آزمون‌های یکپارچه‌سازی با Vitest:

```bash
# اجرای یکباره کلیه آزمون‌ها
npm run test

# اجرای تست‌های پایپ‌لاین AI به صورت ایزوله
npx vitest run tests/ai-pipeline.test.ts

# اجرای تست‌های رندرینگ PDF به صورت ایزوله
npx vitest run tests/pdf-render.test.tsx

# دریافت گزارش پوشش کد (Coverage Report)
npm run test:coverage
```
